# MarketPulse

**MarketPulse** is a free, educational paper-trading platform. It lets you practice investing in real stocks and cryptocurrencies using simulated funds — real market data, real portfolio math, zero real money at risk.

This is a solo full-stack project built to practice and demonstrate modern MERN development: authentication, real-time data integration, AI-powered features, and a polished, responsive, dark-mode-ready UI across two separate front-end applications.

> 🎓 **Educational project.** No real money, securities, or cryptocurrency are ever bought, sold, or held. AI Insights are generated for learning purposes and are not financial advice.

## Features

**Trading & Portfolio**
- Buy and sell real stocks and cryptocurrencies with simulated funds ($10,000 starting balance)
- Live prices sourced from Finnhub (stocks) and CoinGecko (crypto)
- Full portfolio view: holdings, average cost, current value, profit/loss, asset allocation
- Complete transaction history with search and filtering
- Watchlist to track assets without holding them

**AI Insights**
- On-demand, portfolio-specific analysis generated by an LLM (Groq / Llama 3.3), based only on your actual holdings and performance data
- Cached per user with a manual refresh option to control API usage

**Authentication**
- Email/password signup and login
- Google OAuth (Sign in with Google)
- Secure password reset via email (Resend)
- HTTP-only JWT cookies, environment-aware cookie security for local vs. production

**Design**
- Fully responsive across mobile, tablet, and desktop
- Dark mode on the marketing site
- Two purpose-built front ends: a marketing/landing site and a separate trading dashboard app

## Tech Stack

**Frontend**
- React (Create React App)
- React Router
- Bootstrap 5 + custom CSS (CSS variables for theming)
- Recharts (portfolio & performance charts)
- react-icons / Font Awesome

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT authentication with HTTP-only cookies
- bcryptjs for password hashing

**Third-Party Services**
- [Finnhub](https://finnhub.io) — live stock market data
- [CoinGecko](https://www.coingecko.com) — live cryptocurrency data
- [Groq](https://groq.com) — LLM-generated AI portfolio insights
- [Resend](https://resend.com) — transactional email (password reset)
- Google OAuth 2.0 — social login

## Project Structure

This is a monorepo with three independent applications:

```
marketpulse/
├── backend/       Express API — auth, portfolio, trading, market data, AI insights
├── dashboard/     React app — the actual trading platform (behind login)
└── frontend/      React app — public marketing site, signup/login, password reset
```

Each has its own `package.json` and is deployed independently.

## Running Locally

### Prerequisites
- Node.js 18+
- A free MongoDB Atlas cluster (or local MongoDB)
- API keys: [Finnhub](https://finnhub.io), [Groq](https://console.groq.com), [Resend](https://resend.com), [Google OAuth Client ID](https://console.cloud.google.com)

### 1. Clone the repo

```bash
git clone https://github.com/Afif2211/marketpulse.git
cd marketpulse
```

### 2. Backend setup

```bash
cd backend
npm install
```

Create `backend/.env`:

```env
PORT=8000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
FINNHUB_API_KEY=your_finnhub_key
GOOGLE_CLIENT_ID=your_google_client_id
RESEND_API_KEY=your_resend_key
GROQ_API_KEY=your_groq_key
NODE_ENV=development
FRONTEND_URL=http://localhost:3000
DASHBOARD_URL=http://localhost:3001
```

```bash
node server.js
```

API runs at `http://localhost:8000`.

### 3. Dashboard app setup

```bash
cd dashboard
npm install
```

Create `dashboard/.env`:

```env
REACT_APP_API_URL=http://localhost:8000/api
```

```bash
npm start
```

Runs at `http://localhost:3001` (configure the port in `package.json` scripts if needed, or via `PORT=3001 npm start`).

### 4. Frontend app setup

```bash
cd frontend
npm install
```

Create `frontend/.env`:

```env
REACT_APP_API_URL=http://localhost:8000/api
REACT_APP_DASHBOARD_URL=http://localhost:3001
REACT_APP_GOOGLE_CLIENT_ID=your_google_client_id
```

```bash
npm start
```

Runs at `http://localhost:3000`.

## Deployment

- **Backend** deployed on [Render](https://render.com)
- **Dashboard & Frontend** deployed on [Vercel](https://vercel.com)

When deploying, set the same environment variables as above in each platform's dashboard, with real production URLs in place of `localhost`, and `NODE_ENV=production` on the backend. Remember to also add your production frontend URL to the **Authorized JavaScript origins** list for your Google OAuth Client ID in [Google Cloud Console](https://console.cloud.google.com).

## Notes & Limitations

- This is a portfolio/learning project, not a production financial product.
- Password reset emails are sent via Resend's free tier, which — without a verified custom domain — can currently only deliver to the email address the Resend account was created with.
- AI Insights are generated from portfolio numbers only and should not be treated as real investment advice.
